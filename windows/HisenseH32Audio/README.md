# Hisense H32 Audio per Windows 11

Trasmette l'audio di `CABLE Output (VB-Audio Virtual Cable)` al ricevitore Scream
della TV tramite multicast `239.255.77.77:4010`.

- doppio clic sull'icona nell'area di notifica: avvia/ferma;
- menu contestuale: stato e avvio automatico con Windows;
- uscita Windows da selezionare: `Altoparlanti (VB-Audio Virtual Cable)`;
- non richiede Test Mode e non modifica Secure Boot.

Il driver VB-CABLE resta software di VB-Audio e non viene incorporato nel progetto.
